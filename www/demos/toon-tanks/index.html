Save The Turtle

C++ et MonoGame à la rescousse des tortues...

Ce prototype de 2015 est un de nos premiers tests sans moteur de jeu. Il a été réalisé en C++ avec la librairie MonoGame. Le but était d'aider les tortues à rejoindre la mer en évitant les obstacles. Pour cela le joueur doit creuser des trous dans le sable.

Caractéristiques

Ce prototype est une démonstration qui implémente les options suivantes

Attention, ce prototype n'est pas un jeu complet.

MonoGame et SDL

C'est une implémentation qui n'utilise pas moteur de jeu commercial. Les librairies MonoGame (anciennement Microsoft XNA) permettent de créer des jeux multi-plateformes. SDL est une librairie d'affichage 2D reconnue.

Moteur maison

Il a été réalisé en C++, ce qui permet une utilisation compléte des boucles de jeux (game loop).

Heightmap

La heigthmap (représentée par différentes teintes), permet de retirer du sable ce qui ralentit et dirige les petites tortues.

UI

Les informations utiles, telles que les nombre d'images par secondes (FPS), la résolution et le scrore sont affichées en haut de l'écran.

Contrôles

Le prototype est jouable a la souris. Le joueur doit creuser des trous dans le sable pour diriger les tortues.

Graphismes

Les graphismes sont simples et efficaces. Ils ont été réalisés a partir d'images de vraies tortues marine.
